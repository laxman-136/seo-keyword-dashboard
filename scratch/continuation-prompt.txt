## README Update

```markdown
## Leads Dashboard — Live TeleCRM Integration

Data source: TeleCRM API (live, refreshes every 15 minutes)

### Setup
1. Add to `.env.local`:
   TELECRM_API_TOKEN=your_sync_token
   TELECRM_ENTERPRISE_ID=your_enterprise_id

2. Generate Sync API token:
   TeleCRM → Settings → Integrations → Website/API → Create Token → Select "Sync APIs"

3. Find Enterprise ID:
   TeleCRM → Settings → Integrations → shown in API section

### What's live
- Total leads, by status, by course, by channel
- Pipeline funnel (all 16 stages)
- Monthly trend (auto-calculated, no manual entry)
- Conversion rate (Enrolled / Total)

### Fallback
If TeleCRM API is unavailable, last cached data shown with warning banner.
Historical months (before TeleCRM) still read from Google Sheets `Leads Monthly` tab.
```
